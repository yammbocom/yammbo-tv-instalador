# Yammbo Tv Instalador

Descargas de las apps que preparan un televisor con Yammbo Tv.

| App | Para qué sirve |
|-----|----------------|
| Yammbo Tv Instalador | La que se descarga en la tele. Instala Yammbo Tv Configurador, que deja la tele lista: quita las apps de publicidad que la hacen lenta, instala Yammbo Tv, SmartTube y ProtonVPN, y pone la pantalla de inicio de Yammbo Tv. Todo se puede deshacer. |
| Yammbo Tv Home | La pantalla de inicio. Se actualiza sola desde aquí. |

Instrucciones: https://tv.yammbo.com/install#instalador

Las descargas de cada versión están en [Releases](../../releases). Los releases `instalador-N` son el Instalador; los `home-N`, la pantalla de inicio.
